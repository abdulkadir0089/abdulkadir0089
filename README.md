# Hi, I'm Abdul Kadir 👋
### WordPress & Front-End Web Developer | SEO Specialist

I design and build clean, responsive websites with WordPress, HTML and CSS,
then help them get found on Google through keyword research, on-page SEO,
technical SEO and competitor analysis.

## 🛠 Services
- **Website Design & Development** – responsive websites built with WordPress, HTML and CSS
- **WordPress Websites** – Elementor builds, theme customization, forms and plugin setup
- **SEO Audits** – finding technical and on-page issues, with a prioritized fix list
- **Technical SEO** – indexing cleanup, redirects, HTTPS migration, Search Console
- **On-Page SEO** – focus keywords, titles, meta descriptions, headings, internal links, image alt text
- **Keyword & Competitor Research** – finding the searches your customers make and what ranks for them
- **SEO Content** – long-form blog posts and service pages written to rank
